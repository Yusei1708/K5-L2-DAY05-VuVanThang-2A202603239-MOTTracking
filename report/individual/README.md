# Báo cáo cá nhân

Báo cáo phải được đổi tên theo MSSV và họ tên không dấu:

```text
report/individual/MSSV_HoTen.md
```

Ví dụ: `report/individual/20241234_NguyenVanAn.md`.

Ảnh chụp màn hình đặt trong `report/individual/images/`. Ít nhất 3 ảnh đoạn bị che: `che_1_truoc.png`, `che_2_giua.png`, `che_3_sau.png`. Chỉ cắt vùng cần thiết, không chép nguyên frame MOT17 độ phân giải gốc.
